# IRlist 1.2.0 — نسخه نهایی فعلی

## اجرای برنامه در ویندوز
1. ZIP را کامل Extract کنید.
2. وارد پوشه `IRlist` شوید؛ همان پوشه‌ای که `package.json` داخل آن است.
3. در نوار آدرس File Explorer بنویسید `cmd` و Enter بزنید.
4. اجرا کنید:

```bash
npm install
npm run dev
```

5. آدرس `http://localhost:5173` را باز کنید.

برای توقف سرور در CMD از `Ctrl + C` استفاده کنید.

## امکانات فعلی
- صفحه انتخاب بین «زندگی شخصی» و «کار و تیم» بدون لوگو، نام برنامه، متن انگلیسی یا آیکون.
- فضای شخصی تک‌صفحه‌ای و بدون منوی کناری؛ شامل سه لیست وظایف، درصد پیشرفت هر لیست، اهداف کوتاه‌مدت و بلندمدت و دفتر شکرگزاری با تم تیره.
- فضای کاری با منوی کناری، لوگوی IR و جمله «تو بهترین هستی ...».
- وظایف، اهداف و شکرگزاری شخصی با فضای کاری جدا هستند.
- بخش مالی کاری شامل پیگیری پیش‌پرداخت/تسویه پروژه و پرداخت حقوق اعضای تیم با چک‌باکس و ذخیره وضعیت.
- پروژه‌ها، اعضای تیم، پشتیبان‌گیری و بازیابی اطلاعات.
- ذخیره محلی در IndexedDB.

## نکات مهم
- دیتابیس محلی عمداً همان `irlist-local-v1` نگه داشته شده تا اطلاعات نسخه‌های قبلی در همان مرورگر و همان origin در دسترس بماند.
- برای جلوگیری از نمایش نسخه قدیمی، کش Service Worker به نسخه جدید ارتقا یافته است. اگر هنوز نسخه قبلی دیده شد، یک بار صفحه را با `Ctrl + Shift + R` تازه‌سازی کنید.
- نسخه فعلی به صورت پیش‌فرض محلی است. برای همگام‌سازی ابری باید اطلاعات Supabase در `.env` تنظیم و جداول SQL اجرا شوند.
- اعلان Push و همگام‌سازی آفلاینِ مقاوم هنوز در این نسخه فعال نیستند.


## نصب روی گوشی (PWA)
این پروژه به‌صورت وب‌اپ قابل نصب روی صفحه اصلی گوشی آماده شده است؛ برای نصب روی iPhone باید ابتدا روی یک آدرس HTTPS منتشر شود.

### انتشار
1. پروژه را روی Vercel یا Netlify منتشر کن (Build command: `npm run build`، Output directory: `dist`).
2. پس از انتشار، آدرس HTTPS سایت را روی Safari آیفون باز کن.
3. دکمه Share را بزن و گزینه `Add to Home Screen` را انتخاب کن؛ نام IRlist را تأیید و Add را بزن.
4. آیکون IRlist روی صفحه اصلی ظاهر می‌شود و برنامه در حالت مستقل باز می‌شود.

### نکته مهم
اجرای `localhost` روی کامپیوتر، به‌تنهایی برنامه را روی آیفون نصب نمی‌کند. گوشی باید به نسخه منتشرشده با HTTPS دسترسی داشته باشد. این نسخه PWA است، نه فایل IPA و نه اپ منتشرشده در App Store. ذخیره محلی هر دستگاه جداست؛ برای همگام‌سازی بین گوشی و کامپیوتر باید Supabase تنظیم و حساب کاربری استفاده شود. اعلان Push آیفون نیز هنوز در این نسخه فعال نشده است.
